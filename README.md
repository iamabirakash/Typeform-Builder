# Typeform Clone

This project is being implemented phase-by-phase. The first checkpoint scaffolds a Next.js 14 App Router frontend and a FastAPI backend with CORS and health-check wiring.

## Phase checkpoints

Each implementation phase is completed and verified before requesting approval to proceed to the next phase.

## Local development

Frontend: `cd frontend`, install dependencies with `npm install`, then run `npm run dev`.

Backend: create a virtual environment in `backend`, install `requirements.txt`, then run `uvicorn app.main:app --reload --port 8000`.
